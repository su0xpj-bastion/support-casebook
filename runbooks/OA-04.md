# OA-04 — Prepaid credit balance exhausted

*Provider:* openai · *surface:* api · *kind:* error · *retry:* N · *weakest provenance:* `synthesized`

## Confirm it
- http.status
- error.code

Easily confused with: OA-01, OA-02, OA-05

## Fix and customer guidance
**Retry:** N

Retrying won't restore access. An org owner adds prepaid credits (Billing). Stop automatic retries on this code: both official SDKs retry every 429 twice by default.

Sources: https://developers.openai.com/api/docs/guides/error-codes

## Escalate when
Not a platform bug: route to the customer's admin (and the account team for tier/billing changes). Escalate only if the documented fix doesn't change the evidence.
