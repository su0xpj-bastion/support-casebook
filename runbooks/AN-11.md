# AN-11 — 504 timeout_error; SDK retries create several request-ids per logical call

*Provider:* anthropic · *surface:* api · *kind:* error · *retry:* C · *weakest provenance:* `synthesized`

## Confirm it
- all request-ids for the logical call
- max_tokens
- stream false

Easily confused with: AN-08, AN-10

## Fix and customer guidance
**Retry:** C

Stream long requests (or use Batches); give support every request-id for the logical call. Blind retries of long non-streaming calls repeat the work.

Sources: https://platform.claude.com/docs/en/api/errors

## Escalate when
Escalate to the provider/platform incident channel with request IDs, UTC window and blast radius once two or more customers or keys show it.
