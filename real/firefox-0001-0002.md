# Two Firefox-only bugs found by cross-browser tests

**Source:** [web-e2e-qa](https://github.com/su0xpj-bastion/web-e2e-qa) `docs/bugs/0001`, `docs/bugs/0002`. Both fixed in the app under test.

## BUG-0001 — "Skip to content" doesn't move keyboard focus (S2, accessibility)
- **Symptom:** keyboard and screen-reader users can't bypass the header in Firefox.
- **Evidence:** Playwright `expect(locator('main')).toBeFocused()` → `Received: inactive` on `firefox-desktop` only; trace and video attached.
- **Root cause:** fragment navigation (`href="#main"`) always scrolls, but only some engines move focus to a `tabindex="-1"` target.
- **Fix:** move focus explicitly on activation.

## BUG-0002 — navigating away mid-request throws an unhandled rejection (S3)
- **Symptom:** `pageerror: NetworkError when attempting to fetch resource.` in error monitoring, Firefox only, about 1 run in 5.
- **Why intermittent:** only when navigation lands while `/api/me` is in flight (reproduced with `--repeat-each=5`).
- **Fix:** treat a `TypeError` from `fetch` as "can't reach the server"; verified with `--repeat-each=10`.

## Support lesson
"Only some users, only sometimes" — capture browser + version and a repeat count before calling it a heisenbug.
