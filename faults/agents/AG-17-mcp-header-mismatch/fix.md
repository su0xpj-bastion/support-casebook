# AG-17 — Gateway drops Mcp-Method/Mcp-Name or rewrites MCP-Protocol-Version

Pass Mcp-Method, Mcp-Name and MCP-Protocol-Version through every proxy unchanged. A client that silently fell back to the handshake era is the tell.
