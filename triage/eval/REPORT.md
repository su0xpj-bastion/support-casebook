## Reading it

Both models run locally on Ollama, for free. No paid frontier model was run.

- **Rules alone never give a wrong answer** (safe 1.000, 0 wrong). They ask for more information on 44% of tickets, because a bare status or a vague symptom can't separate retryable from non-retryable causes.
- **An LLM alone is unsafe at this size:**
  - qwen2.5:1.5b: **25** false "retry" verdicts and 37 invalid-JSON errors.
  - gemma3:1b: **49** false "retry" verdicts, and 44% of its quotes don't appear in the ticket.
- **The guard is what makes the combination safe.** Combined mode keeps false "retry" verdicts at **0** for both models; the guard stepped in 50 times for qwen and 82 for gemma. It resolves more tickets than rules alone (strict 0.661 / 0.626 vs 0.564). The cost is wrong-but-not-retry answers: **16 with qwen, 5 with gemma**. The weaker model ends up safer because more of its output gets rejected.
- **Correction:** an earlier version of this report scored LLM errors (invalid JSON) as safe abstains. Errors are now counted and shown separately, with a "safe, errors counted as failures" column. The gates were unaffected.
- **Decision:** combined output is a draft for a human. Only rules-only answers go to customers automatically.
